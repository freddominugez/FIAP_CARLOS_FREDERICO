# Definition of Ready e Definition of Done

Base: DDD aula 9. Vale para cada funcionalidade da matriz.

## Pronta para começar (DoR)

- [ ] Requisito com ID na matriz de rastreabilidade
- [ ] Regra de negócio escrita, com exceções
- [ ] Comando e evento aparecem no Event Storming
- [ ] Nomes conferidos com a linguagem ubíqua
- [ ] Rota, perfil e códigos de erro definidos
- [ ] Critério de teste escrito antes do código
- [ ] Cabe em um dia de trabalho

## Pronta para fechar (DoD)

- [ ] Testes unitários do domínio passando
- [ ] Teste de integração com PostgreSQL real passando
- [ ] Cobertura do módulo ≥ 80%
- [ ] Rota documentada no Swagger com exemplos
- [ ] Lint e SonarCloud sem problema novo
- [ ] Nenhum dado pessoal em log
- [ ] Matriz atualizada com teste e commit
- [ ] Merge na `main` por PR com CI verde
